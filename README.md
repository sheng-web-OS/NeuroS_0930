# 2023 AHA/ASA 動脈瘤性蜘蛛膜下腔出血指引：繁中逐段翻譯與圖表解讀

原始文獻：Hoh BL, et al. *2023 Guideline for the Management of Patients With Aneurysmal Subarachnoid Hemorrhage*. Stroke. 2023;54:e314-e370. DOI: 10.1161/STR.0000000000000436.

## 使用方式

- 本譯本按原文章節拆檔，段落後標示原文電子頁碼（e-page），方便回查。
- `COR` 為推薦等級（Class of Recommendation），`LOE` 為證據等級（Level of Evidence）。推薦強度與證據品質是兩條不同軸線，不能把低證據等同於不該做。
- 支持文字依原文順序翻譯並於章節標示電子頁碼；為維持可讀性，個別引文編號不逐一重印，需追查研究時請依頁碼回到原 PDF 的 References。
- 表格不是只翻欄位，而會另附「如何讀」：它在決策鏈中回答哪個問題、適用邊界與容易誤讀之處。
- 本文件供臨床學習與報告整理，不取代病人層級的專科判斷。

## 全文決策骨架

1. **先辨識事件**：病人是否可能為 aSAH？應如何排除或證實？
2. **再穩定系統**：轉送何處、如何監測，並防止再出血與全身性併發症？
3. **盡快封閉破裂源**：何時處置、治療目標為何、clip 與 coil 如何選？
4. **處理腦部次級傷害**：水腦、癲癇、血管痙攣與延遲性腦缺血如何偵測與治療？
5. **把存活延伸成恢復**：如何評估功能、認知、情緒與生活品質，並追蹤殘餘、復發或新生動脈瘤？
