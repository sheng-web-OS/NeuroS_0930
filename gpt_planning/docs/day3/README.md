# Day 3｜藥物、術後照護與報告整合（待完成）

## 上游前提

術後藥物不是「栓塞後固定吃多久」，而是由 **implant thrombogenicity × rupture status × bleeding procedures × patient response** 共同決定。

## 預定產出

| 模組 | 問題 | 產出 |
|---|---|---|
| Antiplatelet causal model | 為何某裝置需要 DAPT？ | implant location、metal burden、endothelialization 與 thrombosis 圖 |
| Regimen matrix | 哪個裝置需要何種藥物？ | 裝置 × premedication × maintenance × duration × exceptions |
| Evidence boundary | 3、6、12 個月的證據來自哪裡？ | SNIS、Enomoto、DAPTS ACE 對照 |
| Ruptured pathway | EVD、SAC/FD 與 hemorrhage 如何衝突？ | Procedure sequence 與 escalation plan |
| Post-op care | neuro exam、access site、BP、imaging、complications | 術後 0–24 h、出院、追蹤時間軸 |
| Final report | 將 Day 1–3 組成投影片 | 每張 slide 只有一個可辯論命題 |

## 必須承接的 Evidence IDs

- C18–C19：acute rupture、DAPT、EVD。
- C43–C44：intrasaccular device 與 guideline scope。
- C45–C47：Enomoto cohort。
- C48–C49：DAPTS ACE RCT。
