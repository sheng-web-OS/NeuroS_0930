# Q10–Q18｜核心文獻角色與證據階層

## Evidence matrix 欄位

每一列只放一個可引用主張，固定包含：population、R/U、location/morphology、intervention、comparator、outcome/time、effect、design、limitation、report placement。

## 七篇核心文獻

| 文獻 | 能回答什麼 | 不能回答什麼 | Evidence IDs |
|---|---|---|---|
| [AHA/ASA 2023 aSAH guideline](https://doi.org/10.1161/STR.0000000000000436) | 破裂瘤 timing、posterior coiling、large ICH、good-grade anterior circulation、SAC/FD 邊界 | 不能回答 UIA 是否 preventive repair；primary coiling 推薦不能外推所有 device | C01–C19 |
| [ESO 2022 UIA guideline](https://pmc.ncbi.nlm.nih.gov/articles/PMC9446328/) | UIA rupture risk vs treatment risk；modality complication factors；shared decision | 沒有 completed RCT 證明整體 clipping 或 endovascular 優越 | C20–C37 |
| [Liang 2024 endovascular review](https://pmc.ncbi.nlm.nih.gov/articles/PMC11449534/) | coil、BAC、SAC、FD 的機轉與演進 | Narrative review 不能單獨支撐 comparative effectiveness | C41 |
| [Shao 2024 intrasaccular review](https://pmc.ncbi.nlm.nih.gov/articles/PMC11508718/) | wide-neck 定義、intrasaccular mechanism、DAPT 概念 | WEB 經驗不能外推所有囊內裝置 | C42–C43 |
| [SNIS 2023 antiplatelet guideline](https://doi.org/10.1136/jnis-2022-019844) | neurointerventional antithrombotic 原則與個別化 | 沒有所有裝置通用的單一劑量與時長 | C44 |
| [Enomoto 2024 cohort](https://pmc.ncbi.nlm.nih.gov/articles/PMC11041548/) | SAC/FD 實務劑量、事件時間分布、探索性 duration signal | survivor selection 與 confounding 使其不能證明短療程等效 | C45–C47 |
| [DAPTS ACE RCT](https://pmc.ncbi.nlm.nih.gov/articles/PMC10850618/) | SACE 後 3 vs 12 months DAPT 的直接比較 | 事件與樣本不足，不能宣稱 equivalence；不涵蓋 FD | C48–C49 |

## 證據標籤

| 標籤 | 可做的事 | 不可做的事 |
|---|---|---|
| G | 引用 guideline recommendation 與其適用條件 | 不忽略 LOE、supportive text 母體與裝置世代 |
| RCT | 比較 intervention effect | 不把 underpowered、subgroup 或 landmark analysis 寫成 definitive conclusion |
| C | 描述自然史、風險關聯、real-world outcomes | 不把 treatment selection 後的差異寫成因果 |
| N | 說明機轉、分類、技術演進 | 不單獨證明臨床優越性 |
| Synthesis | 建立報告流程與決策順序 | 必須明示這是作者整合，而非 guideline recommendation |

## Stop rule

每個報告主張都能回答「哪篇文獻、哪個母體、哪個設計、哪個限制」後，停止做一般性摘要。
