# Q19、Q27｜位置不是原因：手術風險機轉

## A：一句結論

**動脈瘤位置只是手術難度的代理變項；真正改變 clipping 風險的是 exposure、proximal control、branch/perforator preservation、neck quality，以及是否同時需要 evacuation/decompression。**

## 從位置名稱拆成可驗證資料

| 風險構面 | 需要的影像／臨床資料 | Clipping 的失敗模式 | Endovascular 的對應失敗模式 |
|---|---|---|---|
| 深度與手術走廊 | skull base relation、cistern、brain retraction、dome projection | exposure injury、premature rupture、無法取得操作角度 | tortuous access、catheter instability |
| Proximal control | parent artery 可否在 rupture 前安全控制 | rupture 時無法快速控制出血 | balloon/proximal flow control 亦可能受 access 限制 |
| Neck / parent artery | neck width、calcification、atheroma、stenosis | incomplete closure、parent stenosis、clip slippage | coil protrusion、device malapposition、incomplete neck coverage |
| Daughter branch | originates from neck、sac 或只是鄰近 | inadvertent branch occlusion；亦可直接重建 | jailed branch、coil protrusion、stent/FD coverage |
| Perforator | 是否可在術野或 angiography 可靠辨識 | 深部穿通枝夾閉或熱損傷 | perforator coverage、thromboembolism |
| Hematoma / mass effect | volume、midline shift、ICP、neurological deterioration | 開顱可同時 evacuation + securing | securing 後仍可能需第二次手術與時間延遲 |

## Branch preservation checklist

1. Branch 是否從 **neck**、**sac** 或鄰近 parent artery 發出？
2. Clipping 是否能在直視下完成 reconstruction？
3. Coiling 是否需要 balloon 或 stent 才能避免 protrusion？
4. FD 是否會覆蓋缺乏 collateral 的重要 branch/perforator？
5. WEB 是否可能 protrude，進而需要 bailout stent 與 DAPT？

## Evidence

- C04–C05：posterior circulation 若 amenable to coiling，破裂期偏 coiling。
- C06–C08：large ICH 使 evacuation/decompression 成為上游需求。
- C30–C33：posterior、calcification、wide neck 與不同 modality complications 的觀察性關聯。
- C42–C43：wide neck 與 intrasaccular device 的形態／implant 邊界。

完整數字見 [Evidence Matrix](../02-evidence/evidence-matrix.md)。

## Counterexample

後循環 clipping 困難，不代表 FD 一定安全；穿通枝豐富或 branch-bearing segment 可能使 clipping、stent、FD 都具有不同形式的 ischemic risk。

## Slide output

**標題：位置只是標籤，風險來自解剖結構**

- 走廊與 proximal control：能不能安全到達？
- Branch/perforator：能不能完成 reconstruction 而不造成 ischemia？
- Hematoma：是否已有獨立的開顱理由？

## Stop rule

當能把「難開」改寫成至少一個可由影像或臨床資料驗證的機轉時，停止使用模糊位置語言。
