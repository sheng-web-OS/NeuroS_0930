# Q20–Q21｜Posterior circulation 與 basilar apex

## A：一句結論

**Ruptured posterior-circulation aneurysm 若 anatomically amenable to primary coiling，指南支持 coiling 優先；但「posterior」本身不能決定是否可 coiling，更不能直接推出 SAC 或 FD。**

## 為何 clipping 的相對代價上升？

| 因子 | Basilar／posterior 的具體問題 | 決策後果 |
|---|---|---|
| 深部暴露 | 靠近 brainstem、cranial nerves 與 skull base | approach morbidity 與 manipulation 增加 |
| Proximal control | 暴露點深、rupture rescue 困難 | premature rupture 代價高 |
| Perforator | basilar apex 周圍穿通枝密集 | clipping 與 FD 都可能造成 ischemia，風險機轉不同 |
| Daughter branches | PCA/SCA/branch incorporation | simple coiling 是否可行取決於 neck 與 branch geometry |
| Device escalation | wide neck 可能需要 BAC、SAC 或 WEB | 若需永久 endoluminal implant，acute DAPT/EVD 會改變淨效益 |

## Evidence

| ID | 主張 | 強度 | 邊界 |
|---|---|---|---|
| C04 | ruptured posterior aneurysm 若可 coiling，coiling 優先 | AHA/ASA COR 1, LOE B-R | 必須 anatomically amenable |
| C05 | posterior subgroup death/dependency RR 0.41（95% CI 0.19–0.92） | RCT subgroup | n=69；樣本小、裝置世代早 |
| C30 | UIA posterior location 與 microsurgical complication OR 7.25；endovascular OR 1.42 | observational meta-analysis | 不是 head-to-head causal comparison |
| C38 | posterior 是相對風險結構，不是手術禁忌 | cross-guideline synthesis | R/U 證據不可合成單一效果量 |

## Basilar apex 尚缺的資料

- Neck width 與 dome-to-neck ratio。
- PCA／SCA 是否由 neck 或 sac 發出。
- Perforator visualization。
- Catheter stability 與 working projection。
- 是否能以 primary coiling/BAC 處理，或必須 SAC/FD。

## Counterexample

若 endovascular 無法保留 branch、無法 secure rupture point，或只能使用高風險 SAC/FD，而 microsurgical reconstruction 可行，就不能因「posterior」標籤排除 surgery。

## Slide output

**標題：後循環使 clipping 相對不利，但不是所有 endovascular treatment 都變得有利**

- Guideline preference：primary coiling **if amenable**。
- Evidence boundary：posterior RCT subgroup 只有 69 人。
- Anatomy gate：neck、PCA/SCA、perforator、device requirement。

## Stop rule

能回答「amenable to coiling」需要哪些 angiographic 條件後，停止重複 posterior circulation 的一般風險描述。
