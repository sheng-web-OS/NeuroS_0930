# Q28｜手術相對不利條件矩陣

> 這張表用於 Slide 4。每一列必須同時包含機轉、替代方案與反例；否則只是禁忌清單。

| 情境 | Clipping 代價的真正機轉 | 可能替代 | 反例／停止外推 | 證據與確定性 |
|---|---|---|---|---|
| Posterior circulation | 深部暴露、brainstem/CN/perforator 鄰近、proximal control 困難 | primary coiling；依 morphology 再考慮 adjunct | 不是所有 posterior lesions 可 coiling；手術困難不代表 FD 安全 | C04–C05、C30、C38；破裂 guideline 中高、UIA observational 低 |
| Basilar apex | PCA/SCA/perforator preservation 與 clip trajectory 複雜 | coiling；wide neck 再比較 BAC/SAC/WEB | 必須取得 neck、branch、projection；無 lesion-specific randomized threshold | 群組證據 + anatomy inference；低至中 |
| Large ICH + depressed consciousness | 已有 evacuation/decompression 的獨立需求 | emergency evacuation with concomitant securing | 小血腫、無 mass effect 時可能先 endovascular | C06–C08；方向中強，但 RCT 小且年代早 |
| MCA bifurcation | 並非天然手術不利；可直接看見 branches、必要時清血腫 | clipping 常合理；特定 anatomy 仍可 endovascular | >65 ISAT finding 是 subgroup，不能普遍化 | C11；低至中 |
| Calcified neck | clip blades 無法均勻閉合，parent stenosis 或 incomplete closure | 依 anatomy 評估 endovascular | 鈣化也可能伴 access、neck、thrombus 問題 | C31；低 |
| Coagulopathy / OAC | 止血與 postoperative hemorrhage risk | 無永久 implant 的 endovascular option | SAC/FD 需 DAPT，可能形成 triple therapy | C32、C44；低 |
| Older age / frailty | 麻醉、開顱恢復、comorbidity、life expectancy | 依 anatomy 與 goal 選擇 | 年齡不是獨立開關；MCA 可能仍偏 clipping | C10–C12、C39；中低 |
| Branch/perforator-rich lesion | 直接夾閉可能造成 branch stenosis 或 perforator injury | coil/BAC/SAC/WEB/FD 依 anatomy | 各種 endovascular device 也可能 jail/cover branch | C18、C33、C42–C43；低至中 |
| Partially thrombosed lesion | true lumen、neck、mass effect 與 reconstruction 複雜 | 個別比較 clipping/bypass、FD、PAO 等 | 兩類治療皆可能失敗；不能單向推論 | **待補 lesion-specific evidence** |
| Cavernous/petrous ICA | skull-base exposure、cranial nerve 與 proximal control | observation、FD、PAO | 需症狀、collateral/BTO 與 specific natural history | **待確認** |

## 可直接口述的結論

「不適合手術」不是位置診斷，而是當 exposure、proximal control、branch preservation、neck quality 或病人耐受性，使預估 surgical morbidity 高於替代方案時形成的**相對結論**。
