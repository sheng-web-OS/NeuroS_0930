# Q32｜病例回測：Ruptured Basilar Apex Aneurysm

## 病例最小資料

65 歲，ruptured basilar apex saccular aneurysm，WFNS grade 2，無 large intraparenchymal hematoma；已知可由 endovascular route 到達，但 neck width、daughter branch incorporation 與 adjunct requirement 未知。

## 決策測試

| 決策層 | 現有答案 | 下一步／停止點 |
|---|---|---|
| Rupture status | Ruptured | 不進 observation 軌；preferably within 24 h securing（C01） |
| Need for open decompression | 無 large ICH | 目前沒有由 mass effect 形成的獨立開顱理由 |
| Modality direction | Posterior；if amenable to coiling，先偏 coiling（C04） | 需要 surgical + endovascular experts 共同判讀 |
| Simple coiling feasible? | 未知 | 補 neck、dome-to-neck、PCA/SCA/perforator、working projection |
| Need SAC/FD? | 未知 | 若需要，acute DAPT、EVD、branch/perforator risk 重新進入比較（C15–C19） |
| When surgery returns | endovascular 無法保留 branch／secure rupture point，或只能使用更高風險 implant strategy | Posterior 標籤不能單獨排除 surgery |

## 暫定結論

**首選方向是 primary coiling if anatomically feasible，不是「任何 endovascular device」。**

## 會改變結論的三項資料

1. Branch incorporation。
2. Neck geometry 與 catheter stability。
3. 是否必須永久 endoluminal implant。

## 反方理由

若 microsurgical clipping 能直接保留 branches，而 endovascular 只能以高風險 SAC/FD 完成，則需重新比較，而不是因 posterior location 維持原結論。
