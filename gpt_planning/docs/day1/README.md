# Day 1｜建立手術決策骨架

## 今日唯一目標

回答：**哪些條件會改變 clipping 與 endovascular treatment 的相對淨效益？**

Day 1 不追求背完所有裝置，也不直接開藥。它先建立上游判斷，使 Day 2、Day 3 不會變成器材與劑量清單。
