# 顱內動脈瘤深度文獻報告：99 項核心問題與三日研究計畫

> 目標不是把七篇文獻全部翻譯完，而是把每一篇文獻轉成可被引用、比較、反駁與整合的證據。每一項任務都必須留下可驗收產出；達到停止點就往下走，未解問題進入不確定性紀錄。

## 一、先固定證據語言

| 標記 | 意義 | 寫作語氣 |
|---|---|---|
| **高** | 指南直接推薦，且母體與問題相符 | 「指南建議／推薦……」 |
| **中** | RCT、前瞻研究或一致的觀察資料，但仍有母體或效力限制 | 「研究顯示／支持……，但……」 |
| **低** | 回溯研究、敘述性回顧、間接比較或機轉推論 | 「可能／可合理推論……」 |
| **待確認** | 核心文獻沒有直接回答，或需要特定中心 protocol、器材 IFU、原始研究 | 不寫成結論；放入 uncertainty log |

### 寫作硬規則

1. **破裂與未破裂分軌。** [AHA/ASA 2023](https://doi.org/10.1161/STR.0000000000000436) 處理 aSAH；[ESO 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9446328/) 處理 UIA。不得因治療名稱相同就直接互相外推。
2. **裝置機轉不等於臨床優越性。** [Liang 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11449534/) 與 [Shao 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC11508718/) 可用來建立器材地圖；若要下比較療效結論，需回到 guideline、trial 或 primary cohort。
3. **未顯著不等於等效。** DAPTS ACE 事件數與收案不足，不能把「沒有統計顯著差異」改寫成 3 個月與 12 個月等效（[Ozaki et al., 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10850618/)）。
4. **研究劑量不等於個人處方。** aspirin 100 mg/day + clopidogrel 75 mg/day 是 Enomoto cohort 中常見維持方案；SNIS 並未替所有 aneurysm device 規定單一 DAPT 時長（[SNIS 2023](https://doi.org/10.1136/jnis-2022-019844)；[Enomoto et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC11041548/)）。

## 六、不確定性紀錄

| 問題 | 為何目前不能回答 | 需要補哪一類來源 | 若三天內找不到，報告如何處理 |
|---|---|---|---|
| 特定裝置的 loading dose 與 local protocol | 核心文獻與各中心做法不完全一致 | IFU、中心 protocol、專科醫師確認 | 不列固定處方，只寫原則與研究方案 |
| 特定 location 的 clipping technical threshold | 指南常以位置群組呈現，不能取代個別手術解剖 | microsurgical series、operative anatomy review | 寫成相對劣勢，不寫絕對禁忌 |
| WEB 或 surface-modified device 是否可使用 SAPT | 裝置、rupture、protrusion 與 adjunct stent 異質 | device-specific prospective study | 標示裝置特異，避免跨裝置外推 |
| FD 在後循環的個別風險 | posterior circulation 內部差異大，穿通枝負荷不同 | posterior-circulation FD cohort/meta-analysis | 保留為高風險選擇，不寫成手術困難時的預設答案 |

## 七、交稿前 QA

| 檢查 | 通過標準 |
|---|---|
| 破裂狀態 | 所有主要主張均標 R 或 U，沒有跨軌外推 |

| 比較對象 | 每個「適合」或「較佳」都寫出與誰相比、在什麼時間尺度 |
| 裝置語言 | coiling、BAC、SAC、FD、WEB 沒有被統稱成同一種栓塞 |
